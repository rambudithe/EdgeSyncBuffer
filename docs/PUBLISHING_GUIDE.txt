=============================================================================
STEP 3 — PUSH YOUR CODE TO GITHUB (5 minutes)
=============================================================================

Open terminal in the EdgeSyncBuffer folder and run:

git init
git add .
git commit -m "Initial release: EdgeSyncBuffer v1.0.0

Offline-first IoT telemetry buffer for .NET with:
- Guaranteed sequence-number-ordered delivery (not timestamp-ordered)
- JSON Lines disk persistence across process restarts
- Configurable dead-letter alerting
- Zero external dependencies beyond System.Text.Json"

git remote add origin https://github.com/rambudithe/EdgeSyncBuffer.git
git branch -M main
git push -u origin main

=============================================================================
STEP 4 — CREATE NUGET ACCOUNT AND API KEY (10 minutes)
=============================================================================

1. Go to nuget.org → Register
   - Use your personal email (same as GitHub)
   - Username: rambudithe

2. After login → Account Settings → API Keys → Create
   - Key Name: GitHub Actions
   - Glob pattern: EdgeSync.*
   - Select: Push new packages and package versions
   - Expiration: 365 days
   - Click: Create

3. COPY THE KEY — you only see it once

4. Add to GitHub repo:
   - GitHub repo → Settings → Secrets and variables → Actions → New secret
   - Name: NUGET_API_KEY
   - Value: [paste your NuGet API key]

=============================================================================
STEP 5 — CREATE YOUR FIRST RELEASE (triggers NuGet publish) (5 minutes)
=============================================================================

In terminal:

git tag v1.0.0
git push origin v1.0.0

This triggers the GitHub Actions CI workflow which:
→ Runs all tests
→ Packs the NuGet package
→ Publishes to nuget.org automatically
→ Creates a GitHub Release with release notes

Wait 5–10 minutes then check:
https://www.nuget.org/packages/EdgeSync.Buffer
